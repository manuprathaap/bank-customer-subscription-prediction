# 🏦 Bank Customer Subscription Prediction

A Deep Learning web application that predicts whether a bank customer is likely to subscribe to a term deposit.

## 📌 Project Overview

This project uses a Neural Network built with TensorFlow/Keras to perform binary classification on bank customer data.

The application takes customer information as input and predicts:

- ✅ Likely to subscribe
- ❌ Unlikely to subscribe

It also displays the predicted subscription probability.

## 🧠 Machine Learning

**Problem:** Binary Classification

**Model:** Neural Network / Deep Learning

**Dataset:** Bank Marketing Dataset

**Target:** Customer subscription to a term deposit

## 🛠️ Technologies Used

- Python
- TensorFlow
- Keras
- Scikit-learn
- Pandas
- NumPy
- Joblib
- Streamlit

## 🌐 Web Application

The project includes an interactive Streamlit application where users can enter customer information and receive a prediction.

### Input Features

- Age
- Job
- Marital Status
- Education
- Credit Default
- Account Balance
- Housing Loan
- Personal Loan
- Contact
- Last Contact Day
- Last Contact Month
- Call Duration
- Campaign Contacts
- Previous Contact Information
- Previous Campaign Outcome
